# VIC-A — объединённый зашифрованный запуск (кандидат)

## Установка без перезаписи работающей версии

1. Закройте текущую браузерную сессию.
2. Перед распаковкой: свойства скачанного ZIP → «Разблокировать», если Windows показывает этот флажок. Это разрешение именно полученному пакету, а не отключение политики PowerShell.
3. Распакуйте ZIP в **`Z:\Iran\Browser\VIC-A-Updated`**.
4. Внутри этой папки должны сразу лежать `Start.cmd`, `Workspace.Common.ps1`, папки `vica` и `vault-preview` (не дополнительная вложенная папка).
5. Запускайте **`Z:\Iran\Browser\VIC-A-Updated\Start.cmd`**.

Существующие `Z:\Iran\Browser\Start.cmd`, `Runtime`, `Working-Vault-Preview`, vault и профиль НЕ заменяются установкой. Пакет использует уже исправленный **`Working-Vault-Preview\WorkingRuntime`**. Старая флешка F: и её пароль больше не нужны.

Пакет исходный: исполняемые файлы Xray/LibreWolf не скачиваются и не включены. Библиотека libsodium и манифест копируются только из ранее установленного `Working-Vault-Preview\vault-preview\lib` в собственную папку пакета через проверенный временный каталог. Архив/версия/хеш проверяются; импорт библиотек и подписи System32 VC Runtime снова проверяются при открытии vault. Самодельный изменённый манифест не является независимым доказательством подлинности — остаётся доверие к ранее выполненной официальной установке.

## Перед меню

Автоматически выполняется изолированная проверка **нового** транспорта на синтетическом процессе: компиляция PS5.1/.NET, аргументы, stdin/EOF, отказ, таймаут, ограничение stderr, захват stdout, удаление SSLKEYLOGFILE из окружения дочернего процесса, завершение всего Job и принудительное завершение владельца. Ни настоящая подписка, ни Runtime, ни сеть не используются. При сбое меню реальных действий не открывается; используйте прежний рабочий запуск. Не удаляйте оставленный тестовый каталог вслепую.

## Меню

- **1 Browser** — пароль vault, проверка конфигурации, подписи LibreWolf и закреплённого официального Xray; запуск через stdin, без открытого config.json.
- **2 Check subscription** — пароль vault, один запрос с сохранённым HWID и `INCY/3.0.28` через собственный SOCKS5h-туннель; строгий разбор и native-проверка кандидата, **без записи vault**.
- **3 Update subscription** — тот же путь; текущий outbound сохраняется только при единственном полном совпадении. Иначе вводится номер узла (адреса/секретные подписи не выводятся). Перед записью требуется **`UPDATE`**. Предыдущая версия остаётся зашифрованным `workspace.vault.backup-…`.
- **4 Validate** — только аутентификация vault и локальная проверка Xray; без подключения к провайдеру/браузера.
- **5 Self-check** — повтор изолированной проверки.
- **0 Exit**.

При неожиданном сообщении не повторяйте UPDATE вслепую. Сначала сохраните только безопасный итоговый текст. Не отправляйте пароль, URL, HWID, конфиг, содержимое vault или сырой ответ.

Окно оставляйте открытым до обычного закрытия браузера. Каждая операция работает в новом процессе PowerShell; при завершении меню остаётся видимым. Порт17890 не освобождается принудительно чужим процессам. Никакого прямого сетевого fallback, curlrc, редиректов или передачи токенов в аргументах командной строки.

## Что изменено в жизненном цикле

**И Xray (проверка/сессия), и curl** создаются приостановленными, с закрытым списком наследуемых трёх pipe-дескрипторов; назначаются в ненаследуемый безымянный Job с KILL_ON_JOB_CLOSE до ResumeThread. Нет запуска без Job при отказе. Очистка подтверждается нулём активных процессов Job и завершением потоков ввода/вывода; иначе сохраняется блокировка и выполняется повтор очистки.

Браузер не назначается в этот Job. Это не обещание, что Windows сохранит его при закрытии всего консольного окна: такое поведение нового пакета пока не проверено на вашем Windows.

## Проверки и границы

На Linux выполнены разбор PowerShell/C#, 39 Python-тестов (криптоформат/исходные контракты/упаковка), компиляция и выпуск IL нового C# с синтаксисом C#5 и ссылками .NET Core3.1, а также проверка размеров шести interop-структур на x64. Это не проверка сборки против .NET Framework: Windows PowerShell5.1 использует .NET Framework4.x, его проверяет встроенный тест. Это **не Windows-исполнение**. Новый Win32 pipe+Job путь требует встроенной проверки на Windows; полный сценарий этого нового ZIP ещё не подтверждён. Прежняя миграция HWID и просмотр YouTube пользователем подтверждены, но не заменяют тест нового транспорта.

- Native `-test` не проверяет доступность сервера; после запуска проверьте YouTube/IP/DNS и отключение туннеля.
- Система не является VPN/системным kill switch. Локальный SOCKS доступен другим локальным процессам; привилегированный/заражённый хост не защищён.
- Профиль, cookies/история браузера, загрузки и старые plaintext-копии не зашифрованы. TEMP и загрузки направлены в WorkingRuntime, но Windows, антивирус, pagefile и crash dumps могут оставлять следы.
- Строки PowerShell/.NET нельзя гарантированно стереть. Вывод/ввод ограничены; нативная диагностика отбрасывается.
- File.Replace/Flush не дают универсальной гарантии при потере питания, враждебной подмене файлов или rollback. Резервная копия хранит прежние ключи.
- Закреплённый Xray не обновляется автоматически; при другой версии нужен отдельный просмотр, без отключения проверок подписи/источника.
- Корневой старый Start.cmd пока намеренно не заменён. Отдельный пакет позволяет вернуться к подтверждённой рабочей версии.
