# LibreWolf + Xray на внешнем SSD (Windows x64)

## Установка

Предполагается обычная Windows 10/11 x64 и доступный диск `Z:`. Администратор не нужен. Скрипт не форматирует диск, не меняет разделы и не удаляет чужие файлы. На ARM64 он намеренно не работает.

1. Сохраните `Install-PortableWorkspace.ps1` на SSD, например в `Z:\Setup`.
2. Просмотрите его содержимое. Откройте обычный PowerShell **без прав администратора**.
3. Целевая папка `Z:\PortableWorkspace` **не должна существовать**; родительская папка должна существовать. Выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File "Z:\Setup\Install-PortableWorkspace.ps1" -Root "Z:\PortableWorkspace"
```

Если Windows пометила скачанный файл как полученный из интернета, после проверки исходника снимите блокировку через свойства файла либо:

```powershell
Unblock-File -LiteralPath 'Z:\Setup\Install-PortableWorkspace.ps1'
```

Это не обход групповых политик: если колледж запрещает PowerShell или запуск программ с внешнего диска, согласуйте запуск с администратором. Не отключайте защиту Windows. Для установки предпочтительнее собственный доверенный компьютер.

Перед скачиванием скрипт показывает метку тома, объём, модель диска, серийный номер и BusType, затем просит ввести полный целевой путь. Сверьте данные с вашим SSD: буква `Z:` и USB BusType сами по себе не доказывают, что выбран нужный накопитель. Если Storage-команды не могут определить один локальный диск, установка останавливается. Не запускайте с повышенными правами только ради обхода этой ошибки — сначала выясните её причину. Сетевые тома и пути через junction/symlink не поддерживаются.

## Результат

```text
Z:\PortableWorkspace\
  LibreWolf\              исходное содержимое официального portable ZIP
  Xray\                   xray.exe и файлы официального ZIP
  install-manifest.json   URL, хеши, версия Xray и сведения о подписи LibreWolf
```

Вложенность LibreWolf сохраняется такой, какой её выпустил проект. Скрипт ничего не запускает, не импортирует старый профиль, не создаёт туннель, не добавляет задачи, службы, ярлыки, системный прокси или записи реестра. Скачивание и распаковка выполняются во временной соседней папке `.install-<случайный ID>` на том же SSD; она удаляется в `finally`. Это не гарантирует отсутствие системных следов скачивания/проверки антивирусом.

**Установка ещё не даёт защищённого браузерного сеанса.** Не входите в аккаунты до отдельной настройки и проверки профиля, SOCKS, DNS, WebRTC и поведения при отключении Xray. Наличие xray.exe само по себе не направляет в него трафик. Конфигурацию и ключи этот этап не запрашивает.

## Откуда скачивается

* LibreWolf: https://librewolf.net/installation/windows/ → официальный `https://dl.librewolf.net/` portable ZIP для x86_64. Не сторонний PortableApps-пакет и не выдуманный GitHub-репозиторий Windows-сборок. Ссылка определяется при запуске; при изменении разметки скрипт завершится ошибкой вместо угадывания адреса.
* Xray: https://github.com/XTLS/Xray-core/releases/latest → `Xray-windows-64.zip`, последний стабильный релиз через GitHub API.

Источник сведений об издателе повторно проверен 2026-11-22: на [официальной странице Windows](https://librewolf.net/installation/windows/) прямо указано: «Windows binaries are signed by OSSign (Scheibling Consulting AB)». Это подтверждает ожидаемую организацию, но не заменяет проверку сертификата конкретного скачанного EXE и не подтверждает точное значение его SimpleName без проверки на Windows.

Создание staging и bundle находится внутри `try/finally`. Очистка выполняется только для staging, успешно созданного этим запуском; ошибка очистки выводится предупреждением, не подменяя исходную ошибку. Принудительное завершение процесса и отключение питания могут оставить временную папку.

Для LibreWolf обязательна действительная Authenticode-подпись `librewolf.exe`, проверяемая Windows. Дополнительно SimpleName сертификата должен точно совпадать с `OSSign (Scheibling Consulting AB)` — полным именем, наблюдаемым в сообщении Windows-проверки пользователя и соответствующим издателю, указанному официальным сайтом. Первоначальное сравнение только с `Scheibling Consulting AB` было ошибочно: SimpleName включает бренд OSSign. Издатель выводится и сохраняется. Это проверка имени в доверенном сертификате, а не закрепление конкретного ключа. Если фактическое имя отличается, скрипт останавливается: сначала проверьте изменение у проекта, не убирайте проверку ради запуска. Точный отпечаток сертификата не закреплён, чтобы не ломать ротацию сертификатов. Остальные файлы ZIP не покрываются проверкой подписи EXE: источник архива защищён HTTPS, отдельная проверка опубликованной подписи всего архива здесь не реализована. SHA-256 LibreWolf в манифесте — локальная запись, а не независимое доказательство подлинности.

Для Xray SHA-256 архива сравнивается с `digest`, опубликованным GitHub API. Если digest отсутствует или отличается, установка останавливается. Хеш и архив поступают от одного поставщика: это не защита от компрометации аккаунта релизов. При сетевых, TLS, сертификатных ошибках и ограничениях API скрипт прекращает работу, а не отключает проверки.

Замечание о редиректах остаётся: `Invoke-WebRequest` следует им автоматически, отдельного списка разрешённых конечных хостов нет. Для GitHub это необходимо учитывать из-за CDN релизов; исходный URL Xray проверяется, а загруженный архив сверяется с digest. Для LibreWolf это дополнительная причина не считать текущую проверку EXE проверкой всего ZIP. Независимая официальная контрольная сумма/подпись ZIP в этой версии не добавлена: её способ публикации ещё не подтверждён.

## Повторный запуск и ограничения

Любая существующая целевая папка, даже пустая, отклоняется. После всех проверок весь комплект публикуется одним переименованием каталога через `Directory.Move` на том же томе, без слияния и перезаписи. Если цель появилась параллельно, операция завершится ошибкой. Для новой версии выберите новую папку, например `-Root 'Z:\PortableWorkspace-New'`. Автоматического обновления установленной копии этот скрипт не настраивает. В официальном portable-пакете может присутствовать собственный updater; установщик его не запускает. Это устраняет последовательное перемещение трёх компонентов, но не гарантирует сохранность при отключении питания, извлечении SSD или аппаратном сбое. Не удаляйте старый профиль автоматически.

В этой Linux-среде полноценная установка и Authenticode-проверка на Windows не выполнялись. Источник и имена актуальных Xray-артефактов проверены через GitHub API; ссылка portable проверена по официальной странице LibreWolf. Нужна пробная установка на собственном Windows-ПК.

## Границы приватности

SSD исправляет узкое место USB 2.0 только при подходящих порте, кабеле и корпусе. Запуск браузера с SSD не изолирует его от чужой Windows. Администратор, EDR или вредоносная программа могут читать профиль, память и клавиатуру. Windows может оставлять журналы, DNS-кеш, crash dump, pagefile и другие следы. Очистка папки не гарантирует их удаления.

Туннель может скрывать содержимое соединений от наблюдателя в локальной сети, но не делает работу невидимой: остаются адрес сервера, время и объём трафика; часть информации доступна конечным сайтам и оператору туннеля. Скрипт не обещает анонимности и не чистит системные журналы. SSD с незашифрованным профилем также раскрывает данные при потере. Для чувствительных аккаунтов предпочтителен собственный доверенный компьютер.
