# VIC-A — последовательный тест пароля и десяти резервных слов

Распакуйте поверх `Z:\Iran\Browser\VIC-A-Password-Test`, сохранив существующий test-data. Запускайте Start-Test.cmd. Если ZIP отмечен Windows как скачанный, используйте свойства ZIP «Разблокировать» перед распаковкой; защиту/политику системы не отключайте. Требуется Windows PowerShell5.1 x64 и ранее установленная проверенная зависимость в соседней VIC-A-Updated/vault-preview/lib. Она копируется только в собственную папку теста с прежними проверками хешей/версии/импортов.

## Ровно четыре шага, без меню

1. Задайте пароль один раз: минимум8, максимум256 NFC-символов, минимум6различных; не полностью цифровой, без очевидных повторений/последовательностей и пробелов по краям. Это эвристика, не оценка энтропии. Восемь символов заметно легче перебирать офлайн, длинная резервная фраза не исправляет слабый пароль.
2. Программа покажет НОВЫЕ10случайных резервных слов. Сохраните их вне этого диска. Не присылайте слова или их скриншот в чат. Ранее опубликованные в чате слова не используются повторно.
3. Программа попросит пароль. Она действительно расшифрует и проверит искусственные данные. При успехе зелёное PASSWORD OK; при ошибке можно повторить тот же пароль, не создавая заново фразу.
4. Программа попросит десять слов с одним обычным пробелом между ними. Реальная независимая расшифровка даст зелёное RECOVERY OK. При ошибке можно повторить ТУ ЖЕ фразу.

После обоих успехов шифротекст записывается в уникальный stage, читается с диска и снова проверяется обоими введёнными секретами. Только затем публикуется `test-data/verified-<случайный ID>.vault` и появляется зелёное ALL CHECKS PASSED. Если запись не прошла, будет отдельный этап disk-stage-readback-and-publication, а не неопределённое create-test.

Enter после неудачной проверки повторяет только текущий шаг. EXIT завершает проверку. CMD оставляет окно на паузе после завершения. Успешный выход из консоли не равен успешной проверке: ориентируйтесь на ALL CHECKS PASSED.

Каждый запуск этого линейного теста — НОВАЯ искусственная проверка с новым паролем/фразой, старые тестовые файлы не перезаписываются и не удаляются. Это проверка будущей схемы входа, не финальная программа. В настоящей версии пароль будет задаваться при настройке, а не при каждом запуске.

## Границы

Никаких импорта, чтения рабочего vault/подписки/профиля, браузера или удаления пользовательских данных. Старые рабочие папки сохраняйте. После успешного теста отдельно подготовим продуктивную версию и импорт с новым случайным ключом; тестовый master-secret в неё не переносится.

Криптография не изменена относительно предыдущего8-символьного теста: две независимые обёртки случайного master-secret и аутентифицированный шифротекст, Argon2id13/64MiB/ops3 + AES256GCM. Хеши обеих обёрток связаны с данными, роли и ID проверяются. Технические детали в FORMAT.md, область проверок в VALIDATION.md. Перед пользовательским вводом выполняются17синтетических C#проверок.

Managed-строки/прокрутку консоли/pagefile нельзя гарантированно стереть; заражённый хост не защищён; полной защиты от rollback, подмены файлов и потери питания нет. Старые backup сохраняют свои прежние пароли/данные. Никакого обещания нулевых уязвимостей или гарантированного отсутствия антивирусных обнаружений.

Пользователь ранее сообщил VirusTotal0/60 для предыдущего ZIP и прекращение локального обнаружения Defender. Это не антивирусный вердикт для этой новой сборки; новый ZIP здесь Defender не сканировался. Упрощение сделано ради явно запрошенного последовательного интерфейса и точных этапов, не ради обхода обнаружения.
