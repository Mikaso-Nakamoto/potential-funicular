# Разбор заблокированного тестового пакета

## Образец

- Пользователь сообщил обнаружение Microsoft Defender `Trojan:Script/Sabsik.FL.A!ml`, категория «Троян», критический уровень, действие «Удалено» при скачивании.
- Проверен ZIP из commit `64b969c979ec9b73a8e5c78541945f96b8cb35b7` (сокращение64b969c; URL/commit из журнала пользователя). Полный хеш коммита необходимо сверять через git; идентификатор образца ниже — SHA256 самого ZIP.
- Файл: `downloads/VIC-A-Password-Test.zip`, 73142байта, 17элементов.
- SHA256: **be86129b14d9a5cbc0ff97899cb9953d861add6f3a88d4175860a4f5a2eab6ba**.
- Байты совпали с `git show 64b969c:downloads/VIC-A-Password-Test.zip`. Детерминированная пересборка дала побайтно тот же ZIP. Файл не изменялся ради нового сканирования.

## Что фактически проверено

1. ZIP не повреждён; все SHA256 из внутреннего манифеста совпадают. Нет дублирующихся имён/выхода через `..`/абсолютных путей. Манифест и исходники из того же репозитория — это проверка согласованности, не независимая гарантия безопасности.
2. В ZIP нет EXE/DLL/ярлыков/VBS/JS/пользовательских vault. Есть открытые PS1/C#, CMD запуска, документация и публичный словарь EFF. Криптобиблиотека в ZIP отсутствует.
3. Просмотрены сборщик, CMD, точка входа PS1, загрузчик криптокода, C# envelope/self-tests, базовый VaultCrypto/Vault.Common, bootstrap копирования зависимости и PE/import-проверка.
4. В просмотренном пути теста не найдено загрузчика команд из сети, отправки паролей наружу, доступа к браузерным профилям/продуктивному vault, команд регистрации автозапуска/задач/служб/реестра или отключения Defender/AMSI. Это результат ограниченного исходного обзора, а не доказательство отсутствия всех возможных вредоносных свойств.
5. Семь существующих source/ZIP-контрактов снова прошли. Они не являются антивирусным анализом.

## Реальное поведение и поверхности риска

- `Start-Test.cmd` открыто запускает Windows PowerShell5.1 с `-NoProfile -ExecutionPolicy RemoteSigned`; скрытого окна/EncodedCommand/Bypass нет. Это запуск скриптового приложения, не исполнение C2-команд.
- `Start-PasswordTest.ps1` читает пароль через SecureString. Резервная фраза намеренно выводится пользователю в консоль; BSTR преобразуется в управляемую строку и указатель очищается, но строку/scrollback нельзя гарантированно стереть. Это чувствительная операция, не доказательство эксфильтрации.
- `Password.Common.ps1` компилирует открытые C#-исходники через Add-Type. Перед компиляцией проверяются закреплённые SHA256. Подстановка пути DLL — открытая строковая замена placeholder, не декодирование скрытого payload.
- `VaultCrypto.cs` вызывает libsodium через P/Invoke по абсолютному пути для Argon2id/AES-GCM/случайных чисел/проверки версии. Проверка импорта PE анализирует байты файла, не загружает их как произвольный shellcode. Динамическая компиляция и native interop заслуживают проверки, но **нет доказательства, что именно они вызвали этот Defender-вердикт**.
- Bootstrap читает два файла ранее установленной зависимости из соседнего `VIC-A-Updated/vault-preview/lib`, сверяет манифест/хеш и копирует только их в собственный staged-каталог пакета. Затем повторяются проверки SHA/версии и подписей System32 VC-runtime. Доверие к ранее установленному libsodium и состоянию локального хоста остаётся предпосылкой.
- Запись самого теста ограничена `test-data` внутри пакета: маркер, lock, TEMP, синтетический зашифрованный файл, encrypted stages/backups. Cleanup удаляет собственный stage-файл/каталог зависимости, а не пользовательские деревья. Системная компиляция/проверка подписей может иметь обычные платформенные побочные эффекты; это не sandbox-гарантия.

## Найденные проблемы качества/ограничения

- В комплект без необходимости целиком включён базовый `Vault.Common.ps1`, хотя тест использует только его определения проверок целостности. Продакшн-функции этого файла в тестовом меню не вызываются.
- Более того, оставшийся в нём неиспользуемый `Initialize-VaultCrypto` закреплён на старом исходнике с минимумом16, а тестовая копия `VaultCrypto.cs` намеренно допускает8 и закреплена отдельно в `Initialize-PasswordPreview`. Текущий путь использует второй initializer, но первый при случайном вызове закономерно откажет. Это дублирование/долг архитектуры, **не установленная причина обнаружения**.
- Ошибки интерфейса первоначально скрывались слишком общим сообщением; Enter мог завершить оболочку. Последнее было исправлено до заблокированного образца, но UX ещё не является финальным.
- Восемь символов — ослабление пользовательского порога; Argon2id не превращает слабый пароль в сильный. Управляемая память, backup/rollback, враждебный хост/файловая система и потеря питания остаются ограничениями.

## Чего эта проверка НЕ установила

Здесь нет Windows Defender/MpCmdRun и нет Windows-среды исполнения. Антивирусный скан точного образца не выполнен. Причина `Sabsik.FL.A!ml`, конкретный детектируемый файл и ложноположительный статус **не установлены**. Отсутствие найденного C2/постоянства в исходном обзоре не отменяет обнаружение. Никакой вердикт Microsoft на пересмотр пока не получен, образец внешним сервисам не отправлялся.

## Решение

Не предлагать восстановление/исключения/отключение защиты, не менять архив с целью пройти детект и не называть новую упаковку «чистой». Заблокированный образец сохранён неизменным для воспроизводимости; это не рекомендация его запускать. Рабочий VIC-A-Updated/Runtime/vault не изменён. Импорт и удаление пользовательских данных приостановлены. Следующий внешний шаг — официальный пересмотр точного SHA/образца Microsoft; это действие здесь не выполнено.
