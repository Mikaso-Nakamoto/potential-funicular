# Осторожная автоматическая уборка VIC-A

Распаковать ZIP в `Z:\Iran\Browser\VIC-A-Cleanup`. Закрыть браузер VIC-A и его меню обычным способом. Запустить `Start-Cleanup.cmd` без администратора.

Сначала скрипт запускает офлайн-проверку новой версии: потребуется новый пароль локально. Пароль не записывается. Без успешной проверки удаление не начинается. После этого ввести `CLEAN` один раз — дальше сравнение и уборка автоматические.

Проверяются только `Z:\Iran\Browser\Runtime` и `Z:\Iran\Browser\Working-Vault-Preview\WorkingRuntime`. В них рассматриваются только `Xray`, `LibreWolf`, `private\downloads`. Файл удаляется, только если в `VIC-A-New\Runtime` по тому же относительному пути существует побайтово одинаковый файл. Новый файл удерживается от изменения, старый удаляется через тот же открытый дескриптор, по которому сравнивался; подмена имени между сравнением и удалением не используется. Неразрешённые/занятые файлы остаются. Обход не спускается в junction/symlink. Сессии блокируются; процессы не убиваются. Требуется обычный доверенный локальный ПК, не защита от враждебного администратора.

**Никогда не удаляются** профили, vault, backup, конфиги, скрипты, тестовые наборы, неизвестные папки и уникальные загрузки. Совпадающее имя или версия файла не считаются доказательством. Пустые каталоги остаются. Старые установки после удаления дубликатов могут быть неполными — запускать только VIC-A-New. Это НЕ удаление всех старых папок и НЕ безопасное стирание SSD.

Локальный CSV содержит имена файлов и результат (не содержимое/пароли). Не публикуйте его: имена могут быть приватными. Удаление необратимо обычным способом; одинаковая копия остаётся в новой версии, но это не независимый резервный носитель. Не изменяйте файлы во время уборки. Если новая версия больше не нужна — сначала скопируйте оставшиеся уникальные данные, а не удаляйте её.

На Windows этот помощник здесь не запускался: исходники проверены контрактными тестами, не заявлена проверка реального удаления на вашей машине. Проверка подписки/сети не заменяется офлайн-проверкой; она пока отдельно не подтверждена для новой сборки. Поэтому сейфы и старые профили намеренно сохраняются.
