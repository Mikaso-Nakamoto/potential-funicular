# IRIS — консольная оболочка для рабочего комплекта

Это дополнение к уже работающим скриптам. Подписка, конфигурация Xray, профиль и установленные программы не меняются. Job Object и шифрование данным дополнением не добавляются.

## Установка

Из архива IRIS-Console-Addon.zip положите `Start.cmd` и `Workspace-Console.ps1` в **Z:\Iran\Browser**, рядом с Workspace.Common.ps1, Start-Workspace.ps1, Update-Subscription.ps1 и Runtime. Этот архив не содержит замены рабочих скриптов или секретов.

После просмотра исходника снимите интернет-метку только с нового PS1:

```powershell
Unblock-File -LiteralPath 'Z:\Iran\Browser\Workspace-Console.ps1'
```

Запустите Start.cmd двойным щелчком, без администратора. RemoteSigned применяется только к запускаемому процессу, системная политика не меняется и Bypass не используется. Политики организации могут блокировать запуск — оболочка их не обходит.

Буква диска может отличаться: оболочка ищет Runtime и соседние скрипты относительно собственного расположения. Если Runtime у вас перенесён в другое место, эта версия не пытается угадывать новый путь.

## Заставка

Зацикленная цветная ASCII-анимация: глаз раскрывается, зрачок двигается, глаз периодически моргает. Примерно 12 кадров/с, без звука, сетевых запросов и файлов с анимацией. Любая клавиша открывает меню. Пункт 6 запускает заставку повторно.

Для полной заставки рекомендуется окно минимум 78 столбцов и 29 строк, моноширинный шрифт Consolas/Cascadia Mono. На маленьком окне заставка предложит перейти в меню; для стандартного окна 25 строк предусмотрено компактное меню. Не используйте совсем маленькое окно: строки будут обрезаны. Избежать мерцания во всех хостах PowerShell невозможно; производится перерисовка в той же области, без Clear-Host на каждом кадре. Если анимация нежелательна:

```powershell
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File 'Z:\Iran\Browser\Workspace-Console.ps1' -NoSplash
```

## Меню

1. Запуск браузера и туннеля через прежний Start-Workspace.ps1 **в отдельном окне сеанса**. Меню остаётся доступным. Не закрывайте окно сеанса крестиком; после нормального закрытия браузера оно завершится самостоятельно. Если запуск не удался и окно исчезло, используйте прежнюю прямую команду Start-Workspace.ps1 для диагностики.
2. Запрос обычного закрытия главного окна LibreWolf, только если найден процесс из нужной установки с командной строкой нужного профиля. Процессы не убиваются. Если идентификация не удалась — закройте браузер вручную. Диалоги о несохранённых данных могут задержать выход. Это **не гарантированный аварийный стоп**.
3. Обновление подписки через существующий Update-Subscription.ps1 -UseDeviceHwid. URL и HWID вводятся по-прежнему скрыто, не сохраняются оболочкой. На время этой операции меню блокируется. Активный сеанс должен быть закрыт; существующий lock остаётся в силе.
4. Открытие папки загрузок на SSD. Открытие Проводника может оставлять системные следы, оболочка не обещает их отсутствия.
5. Офлайн-тесты на искусственных данных: Test-Parser.ps1, Test-CryptoPolicy.ps1, Test-DeviceHwid.ps1. Это не проверка сети или отсутствия утечек.
6. Повтор заставки.
0. Выход **только из меню**. Отдельный сеанс автоматически не завершается. После закрытия меню за его окном и процессами нужно следить самостоятельно.

## Что означают показатели

Панель опрашивает локальные данные примерно каждые 2 секунды плюс время системных запросов. Время работы — **время работы панели**, не доказательство непрерывности туннеля.

- Xray files / LibreWolf files — наличие ожидаемых файлов, не проверка подлинности всех бинарников.
- Config policy — проверка JSON прежней Assert-ConfigPolicy, обновляется при изменении времени/размера конфигурации. Не проверяет соединение с сервером. Не независимая защита от локального администратора и подмены файлов.
- SOCKS READY — listener на 127.0.0.1:17890 принадлежит процессу из нужной установки Xray; не результат удалённого handshake. Занятый порт другого владельца отмечается предупреждением, недоступная инспекция — UNKNOWN.
- Processes / Memory — количество и суммарный Working Set процессов, путь которых удалось сопоставить с этой установкой. Это память Windows, не сетевой трафик, не размер профиля. При недоступных данных показан partial/unknown. Другие профили из той же установки могут входить в статистику.
- SSD — объём и свободное место **тома, где лежит Runtime**, не подтверждение модели физического диска или шифрования.
- Config saved — время изменения файла конфигурации, не время последнего успешного соединения.
- REMOTE IP / DNS / LEAKS = NOT TESTED — намеренно без ложного зелёного статуса. Меню не ходит на внешние сайты, не измеряет скорость и не собирает статистику провайдера. Это отдельно проверяется из браузера.

Настройки, ключи, домен сервера, UUID и URL подписки панель не выводит. Анимация и панель не создают логи. Windows, драйверы и сторонний мониторинг при этом могут вести свои журналы.

## Ограничения и проверка

Новая оболочка проверена статически в Linux; запуска Windows PowerShell 5.1 и реального рендера в вашем терминале здесь не было. Сначала испытайте дома. Существующие незакрытые риски остаются: SOCKS без авторизации доступен другим локальным процессам, аварийное закрытие управляющего окна может оставить Xray запущенным, профиль и конфигурация не зашифрованы.

Для первого прогона: заставка → клавиша → меню → пункт 1 → наблюдение статуса → пункт 2 или ручное закрытие браузера → дождаться завершения окна сеанса → убедиться, что порт и процессы освобождены. Пункт 0 не заменяет этот порядок. Старые команды запуска остаются доступны как рабочий резервный путь.
