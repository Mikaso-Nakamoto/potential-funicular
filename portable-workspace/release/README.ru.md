# VIC-A Password Edition — отдельная сборка-кандидат

## Установка

1. Закройте старую браузерную сессию.
2. Распакуйте ZIP в **`Z:\Iran\Browser\VIC-A-New`**, не поверх рабочей версии. Если Windows предлагает «Разблокировать» в свойствах скачанного ZIP, сделайте это перед распаковкой; Defender и системную политику не отключайте.
3. Запустите **`Z:\Iran\Browser\VIC-A-New\Start.cmd`**.

Ничего из старых папок пока не удаляйте. Сборка переиспользует ранее проверенную libsodium из соседней `VIC-A-Updated` только для первоначального копирования зависимости в собственную папку с проверками версии/хеша/импортов. Новые EXE/DLL не скачиваются. Проверенный источник официальной установки остаётся предпосылкой доверия, один манифест её не заменяет.

## Меню и настройка

Заставка — прежний процедурный глаз, `I` переключает глаз/архив. `L` переключает RU/EN. Поля статуса не обещают, что Интернет доступен: наличие локального слушателя — не проверка удалённого сервера. Настройки языка/стиля пока действуют до закрытия меню.

**При первом запуске пункт6** — отдельное подтверждение IMPORT. Он создаёт новый полный Runtime внутри VIC-A-New:

- читает текущий зашифрованный `Working-Vault-Preview\WorkingRuntime\private\workspace.vault` после ввода **действующей старой фразы от рабочего vault**; забытые слова тестового комплекта не нужны;
- без старой рабочей фразы этот импорт невозможен, обхода шифрования нет;
- копирует Xray/LibreWolf, текущий профиль и загрузки WorkingRuntime, не старый корневой Runtime; отказывает на ссылках/reparse points;
- проверяет закреплённый официальный Xray, подпись LibreWolf, политику и native-конфиг;
- задаёт **НОВЫЙ пароль минимум8символов** (максимум256, минимум6различных, без очевидных повторений/цифрового пароля/пробелов по краям); генерирует **НОВЫЕ10резервных слов** и новый случайный ключ;
- показывает слова: сохраните отдельно от диска, не присылайте в чат и не фотографируйте для чата;
- просит новый пароль, затем новые слова для независимой проверки;
- записывает новый зашифрованный файл, проверяет оба способа с диска и публикует каталог целиком. Если Runtime уже есть, повторной настройки/слияния не будет.

Нужен свободный объём для полной копии браузера, профиля и загрузок. На ошибке неопубликованный собственный stage удаляется; исходный Runtime не удаляется/не перезаписывается. Внезапное завершение может оставить stage — не удаляйте его, пока не убедитесь, что процессов из него нет.

## После настройки

- **1** Браузер — только новый пароль, без резервных слов. Ввод требуется для каждой новой операции; в меню пароль не кешируется.
- **2** Проверка подписки без записи — пароль, рабочий HWID + INCY/3.0.28, только собственный SOCKS5h-туннель.
- **3** Обновление — тот же проверенный путь, native-валидация и UPDATE перед encrypted replacement; зашифрованный backup сохраняется. Обе возможности входа остаются действующими.
- **4** Офлайн-проверка vault/конфига.
- **5** Восстановление/смена пароля по10словам — старый пароль не нужен; задаётся новый пароль, слова остаются прежними, ключ и ID меняются. RESET подтверждает запись с encrypted backup.
- **6** Только первоначальный импорт в ещё не существующий Runtime.
- **0** Выход.

Обычное закрытие браузера возвращает управление меню. Не закрывайте консоль во время публикации. Xray/curl в Job с назначением до запуска; native self-check проверяется до реальных действий. Порт не освобождается убийством чужих процессов. Браузер не помещён в Job; его независимость при закрытии общего окна не обещается.

## Что НЕ импортируется автоматически

Старый `Z:\Iran\Browser\Runtime\private\profile` и `downloads` могли содержать уникальные старые данные: текущий импорт использует только WorkingRuntime. Ничего из старого Runtime не удаляется. Тестовый `VIC-A-Password-Test` вообще не читается и его пароль/слова не переиспользуются.

После импорта сначала4, затем2, затем1/YouTube и обычное завершение; после этого3/UPDATE и повторный запуск. Только после подтверждения этого цикла будем отдельно разбирать удаление старых папок. Автоматической уборки здесь нет.

## Проверки и ограничения

Криптографическая схема пароля/фразы подтверждена пользователем в отдельном Windows-тесте. Новый UpdatePayload выполнен реальным C# на Linux: пароль/фраза открывают обновлённые данные, неверный пароль не обновляет. Полная сборка (импорт, новый V03-запуск и V03-refresh) на Windows здесь не исполнялась: это кандидат для поэтапной проверки, не обещание отсутствия ошибок/уязвимостей. Скрипты разобраны статически, зависимости и ZIP проверены. Новый ZIP не имеет подтверждённого Defender/VirusTotal-вердикта.

Для продуктивного контейнера используются новые ключи, не тестовые. Две обёртки ключа, роли/ID и хеши обеих обёрток в аутентифицированном payload; Argon2id13/64MiB/ops3 + AES256GCM. Минимум8 — только разрешённый порог: слабый пароль остаётся уязвим к офлайн-перебору независимо от силы фразы. Старые backup сохраняют старые пароли/данные. Профиль, cookies/история, загрузки и старые конфиги не зашифрованы. Не системный VPN/kill switch; другие локальные процессы могут использовать SOCKS. Управляемые строки, pagefile/scrollback, враждебный хост/файловая система, rollback и потеря питания не защищены универсальной гарантией.
