# Настройка ВКонтакте: от пустого места до работающего бота

Бот живёт **в сообщениях сообщества ВК**. Ссылка, которую тётя будет давать
клиентам, — это ссылка на диалог с её сообществом: `https://vk.me/<адрес>`.

Время на всё: ~15 минут.

---

## Вариант А. Сообщества ещё нет — создаём

1. Откройте ВК → слева **«Сообщества»** → **«Создать сообщество»**.
2. Тип: **«Бизнес»** (подойдёт и «Тематическое сообщество»).
3. Название — так, как клиенты будут искать, например:
   `Массаж · Елена · Тверь`. В описании: адрес, телефон, «запись через сообщения».
4. Загрузите аватар и обложку — по ним люди понимают, что это не бот-мошенник.
5. После создания запомните **адрес сообщества**: он в строке браузера,
   например `vk.com/club123456789` → `group_id = 123456789` (без слова `club`),
   а ссылка для клиентов — `https://vk.me/club123456789`.

Дальше переходите к шагу 1 варианта Б.

## Вариант Б. Сообщество уже есть — чек-лист

Проверьте три места в **«Управление»** (шестерёнка в меню сообщества):

| Где | Что должно быть |
|---|---|
| Управление → **Сообщения** | «Сообщения сообщества»: **Включены**; «Кто может писать»: **Все пользователи** |
| Управление → **Работа с API** → **Ключи доступа** | создан **ключ сообщества** с правами «сообщения сообщества» + «управление сообществом» |
| Управление → **Работа с API** → **Long Poll API** | **Включён**, версия **5.198**, в типах событий — входящие сообщения и `message_event` |

> Названия пунктов ВК иногда переименовывает — ищите по смыслу. Если что-то не
> совпадает, смотрите раздел «Не нашёл пункт в меню» внизу.

---

## Шаг 1. Включить сообщения сообщества

**Управление → Сообщения:**

- «Сообщения сообщества» → **Включены**.
- «Кто может писать сообщения сообществу» → **Все пользователи** (иначе чужие люди
  не смогут написать боту, а значит и записаться).
- «Начальный текст» (приветствие) — рекомендую включить, например:

  > Здравствуйте! 🌿 Нажмите «📅 Записаться», чтобы выбрать удобное время.
  > Если вопрос срочный — просто напишите сюда, я отвечу.

  Это первое, что увидит человек, открыв диалог: он сразу поймёт, что делать.

## Шаг 2. Создать ключ доступа сообщества

**Управление → Работа с API → Ключи доступа → Создать ключ:**

- Отметьте права:
  - **сообщения сообщества** (обязательно — без него бот не может писать);
  - **управление сообществом** (чтобы `scripts/vk_setup.py` сам включил Long Poll);
- Назовите ключ, например `booking-bot`;
- Скопируйте полученный ключ (начинается с `vk1.a.…`) — **показывается один раз**.

Ключ goes в файл `.env`:

```
VK_GROUP_TOKEN=vk1.a.xxxxxxxxxxxxxxxxxxxx
VK_GROUP_ID=123456789
```

> ⚠️ Ключ = полный доступ к переписке сообщества. Не публикуйте его, не кладите в
> `config.toml` и не отправляйте в мессенджеры. Файл `.env` уже в `.gitignore`.
> Если ключ утёк — удалите его в тех же «Ключах доступа» и создайте новый.

## Шаг 3. Включить Long Poll API

Можно **автоматически** (если у ключа есть право «управление сообществом»):

```bash
python3 scripts/vk_setup.py            # посмотреть, что не так
python3 scripts/vk_setup.py --apply    # включить
```

Или **руками**: Управление → Работа с API → **Long Poll API**:

- «Включён» → **да**;
- «Версия API» → **5.198**;
- «Типы событий» → раздел «Сообщения сообщества»: отметить
  **входящие сообщения** (`message_new`) и **нажатие на callback-кнопку**
  (`message_event`).

`message_event` нужен, чтобы у тёти под заявкой работали inline-кнопки
«✅ Подтвердить / 🚫 Отклонить». Если включать его не хочется — поставьте в
`config.toml`:

```toml
[policy]
use_callback_buttons = false
```

тогда кнопки будут обычными текстовыми (тоже работают, просто в диалоге появятся
лишние нажатия).

## Шаг 4. Узнать vk_id мастера (кому слать заявки)

ВКонтакте не показывает числовой id на странице, поэтому делаем через бота:

1. Запустите бота: `python3 -m bot.main` (или `./run.sh`).
2. **Со страницы тёти** напишите в сообщения сообщества любое слово, например «привет».
3. Остановите бота (Ctrl+C) и выполните:

```bash
python3 scripts/doctor.py --whoami
```

Увидите список тех, кто писал боту, с числовыми id:

```
    id 123456      Елена Петрова
```

4. Впишите id в `.env`:

```
ADMIN_VK_IDS=123456
```

Если мастеров несколько (например, тётя и вы для контроля) — через запятую:
`ADMIN_VK_IDS=123456,654321`. Уведомления будут приходить всем.

## Шаг 5. Очень важно: мастер должен написать сообществу ПЕРВЫМ

Правило ВКонтакте: сообщество не может написать человеку, пока человек сам ему не
написал. Иначе уведомления о заявках просто не дойдут.

Поэтому после настройки **тётя должна открыть диалог со своим же сообществом и
написать туда любое сообщение** («привет»). После этого проверьте доставку:

```bash
python3 scripts/doctor.py --send-test
```

Если в личные сообщения пришло «🩺 Тест доставки» — всё работает.

## Шаг 6. Ссылка для клиентов

Когда всё настроено, тётя даёт людям одну ссылку:

```
https://vk.me/club123456789        ← подставьте адрес своего сообщества
```

Куда её положить:

- в статус и описание сообщества;
- в закрепленный пост («Записаться: …»);
- на личную страницу тёти в раздел «Контакты»;
- в ответы клиентам в личке и в комментариях;
- распечатать QR-код и повесить в кабинете
  (генератор: любой «qr code generator», текст = та же ссылка).

Проверить, что ссылка ведёт туда, куда нужно: откройте её в режиме
«инкогнито», будучи не залогиненным в её аккаунт.

## Проверка всего разом

```bash
python3 scripts/doctor.py --all
```

Скрипт последовательно проверит Python, конфиг, `.env`, базу, связь с ВК,
Long Poll, права ключа и доставку сообщения мастеру — и напишет по-русски, что
именно не так и что сделать.

Дальше: [docs/DEPLOY.md](DEPLOY.md) — запуск на ноутбуке как службы.

## Не нашёл пункт в меню / что-то изменилось

Интерфейс ВК меняется. Ориентиры, которые работают всегда:

- все настройки сообщества начинаются с кнопки **«Управление»** (шестерёнка);
- ключи и Long Poll всегда в разделе **«Работа с API»**;
- сообщения сообщества — в разделе **«Сообщения»**;
- если права не дают создать ключ (например, вы не администратор сообщества) —
  пусть владелец сообщества добавит вас в «Управление → Участники → Руководство»
  с ролью «Администратор».

Проверить, что бот вообще видит сообщения, можно в логе:

```bash
journalctl -u massage-bot -f      # если запущен через systemd
# или в терминале, где запущен python3 -m bot.main
```

Напишите боту «привет» — в логе должна появиться строка `← Мария Иванова (222): привет`.
Если строки нет — проблема в Long Poll/ключе, а не в коде.
