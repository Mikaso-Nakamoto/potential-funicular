# Тексты сообщений: все ключи и плейсхолдеры

Любой текст бота меняется в `config.toml`, секция `[texts]`, **без правки кода**:

```toml
[texts]
greeting = """
Здравствуйте, {name}! 🌿
Записаться к {master} можно за пару минут — нажмите «📅 Записаться».
"""
```

Правила:

- Ключ, которого нет в вашем `config.toml`, берётся из встроенных текстов
  (список ниже). То есть достаточно переопределить только то, что хотите
  поменять.
- Плейсхолдеры в `{}` подставляются автоматически. **Не удаляйте их** — иначе
  сообщение потеряет смысл (например, придёт без времени).
- Лишний или опечатанный плейсхолдер бот **не сломает**: он останется в тексте
  как есть (`{when}`), и это сразу заметно в демо
  (`python3 scripts/demo.py --auto`).
- Тесты запрещают «утёкшие» плейсхолдеры, так что ошибка всплывёт на
  `python3 tests/run_all.py`.
- Многострочные тексты пишите в тройных кавычках `"""…"""`.
- После правки: `sudo systemctl restart massage-bot`.

Плейсхолдеры, доступные **везде**: `{master}` `{phone}` `{address}` `{contacts}`
`{card}` `{ttl}` `{hours}`.

Для сообщений о конкретной записи дополнительно: `{id}` `{title}` `{duration}`
`{price}` `{when}` `{when_short}` `{date}` `{name}` `{vk_name}` `{contact}`
`{comment}` `{status}` `{reason}` `{dialog}` `{profile}` `{delta}`.

## Что видит клиент

| Ключ | Когда показывается | Плейсхолдеры |
|---|---|---|
| `greeting` | первое сообщение и возврат в меню | `name`, `master` |
| `unknown` | бот не понял текст | — |
| `menu` | подпись главного меню | — |
| `services_intro` | шаг выбора услуги | — |
| `no_services` | список услуг пуст | — |
| `service_info` | карточка услуги | `title`, `duration`, `price`, `description` |
| `prices` | раздел «Услуги и цены» | `list` |
| `about` | раздел «О мастере» | `master`, `address`, `hours`, `card` |
| `contacts` | раздел «Связаться» | `card` |
| `pick_date` | шаг выбора даты | `title`, `duration` |
| `no_dates` | свободных дат нет вообще | `days` |
| `no_slots` | в выбранную дату окон нет | `date` |
| `pick_time` | шаг выбора времени | `date`, `minutes` |
| `slot_taken` | окно заняли, пока выбирали | `when` |
| `ask_name` | запрос имени | `name` |
| `bad_name` | имя не принято | — |
| `ask_contact` | запрос телефона | — |
| `bad_contact` | не похоже на номер | — |
| `ask_comment` | запрос комментария | — |
| `summary` | «проверьте заявку» | `title`, `when`, `duration`, `price`, `name`, `contact`, `comment` |
| `request_created` | заявка отправлена | `title`, `when`, `master`, `contacts`, `ttl` |
| `too_many_requests` | у клиента уже много заявок | `count` |
| `my_bookings` | список записей клиента | `list` |
| `my_bookings_empty` | записей нет | — |
| `approved_client` | мастер подтвердил | `title`, `when`, `price`, `address`, `phone` |
| `rejected_client` | мастер отклонил | `when`, `reason` |
| `expired_client` | заявка закрылась без ответа | `when` |
| `cancelled_client` | запись отменена | `when` |
| `cancel_too_late` | клиент отменяет слишком поздно | `hours`, `phone` |
| `reminder_client` | напоминание клиенту | `title`, `when`, `address`, `phone` |
| `rescheduled_client` | мастер перенёс запись | `title`, `when`, `address`, `phone` |

## Что видит мастер

| Ключ | Когда показывается | Плейсхолдеры |
|---|---|---|
| `new_request_admin` | новая заявка с кнопками | `id`, `title`, `duration`, `price`, `when`, `name`, `contact`, `comment`, `dialog` |
| `approved_admin` | заявка подтверждена | `id`, `name`, `title`, `when` |
| `rejected_admin` | заявка отклонена | `id` |
| `request_cancelled_admin` | клиент отменил запись | `name`, `title`, `when` |
| `rescheduled_admin` | запись перенесена | `id`, `name`, `when` |
| `reminder_admin` | напоминание мастеру | `name`, `title`, `when`, `delta` |
| `digest` | утренний список записей | `date`, `list` |
| `digest_empty` | записей на день нет | `date` |
| `admin_help` | ответ на `/help` | — |
| `already_decided` | заявка уже обработана | `id`, `status` |
| `request_not_found` | заявки с таким номером нет | `id` |
| `cancelled_by_admin` | запись отменена мастером | — |

## Значения плейсхолдеров

| Плейсхолдер | Что подставляется |
|---|---|
| `{master}` | `contacts.master_name` |
| `{name}` | имя клиента (из профиля ВК или то, что он ввёл) |
| `{vk_name}` | имя из профиля ВК |
| `{phone}` | `contacts.phone` |
| `{address}` | `contacts.address` |
| `{card}` / `{contacts}` | вся карточка контакта: телефон, WhatsApp, Telegram, ВК, адрес, как найти |
| `{dialog}` | ссылка «написать клиенту»: `https://vk.com/im?sel=<id>` |
| `{profile}` | ссылка на страницу клиента |
| `{title}` | название услуги |
| `{duration}` | длительность в минутах |
| `{price}` | цена (`1500 ₽`) |
| `{when}` | дата и время по-русски: `пт, 23 октября в 10:30` |
| `{when_short}` | коротко: `23.10 10:30` |
| `{date}` | только дата: `пт, 23 октября` |
| `{delta}` | сколько осталось: `2 часа 15 минут` |
| `{contact}` | что оставил клиент: телефон или «ВКонтакте: …» |
| `{comment}` | комментарий клиента (`—`, если пусто) |
| `{status}` | статус заявки по-русски |
| `{reason}` | причина отказа, если мастер её указал |
| `{id}` | номер заявки |
| `{ttl}` | сколько мастер обычно отвечает (`1 день`) |
| `{hours}` | лимит самостоятельной отмены в часах |
| `{days}` | глубина записи в днях |
| `{minutes}` | длительность выбранной услуги |
| `{list}` | готовый список (записи, услуги) |
| `{hours}` в `about` | расписание по дням |

## Советы по тону

- Пишите так, как тётя говорит с клиентами: «Здравствуйте» вместо «Хай».
- В отказе (`rejected_client`) обязательно оставляйте `{reason}` и предложение
  выбрать другое время — иначе человек обидится и уйдёт.
- В `approved_client` полезно добавить, что взять с собой и за сколько приходить.
- Эмодзи — по одному на строку, не больше: у старшего поколения пёстрое сообщение
  вызывает недоверие.
- После правки прогоните `python3 scripts/demo.py --auto` и прочитайте всё, что
  увидит клиент, глазами нового человека.
