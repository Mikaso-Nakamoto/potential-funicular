# Инструкция для мастера (тёти) — без технических слов

Распечатайте или перешлите этот файл. Всё управление ботом — **в обычном диалоге
ВКонтакте с вашим сообществом**, там же, где переписка с клиентами.

---

## Главное

Бот сам никого не записывает. Он принимает **заявку**, а решаете вы:
подтвердить, отклонить или перенести. Клиенту бот пишет только после вашего
решения.

## Что приходит, когда кто-то хочет записаться

```
🔔 НОВАЯ ЗАЯВКА №12

🔹 Массаж спины (40 мин, 1500 ₽)
📅 пт, 23 октября в 10:30
👤 Мария Иванова
📱 +7 (900) 123-45-67
💬 Написать клиенту: https://vk.com/im?sel=987654
📝 Комментарий: болит шея после сна

Подтвердить или отклонить — кнопками ниже.
[ ✅ Подтвердить ]  [ 🚫 Отклонить ]
[ 🕒 Перенести ]
```

- **✅ Подтвердить** — время занято, клиенту уходит подтверждение с адресом,
  потом напоминания.
- **🚫 Отклонить** — клиенту уходит вежливый отказ и предложение выбрать другое
  время. Слот снова становится свободным.
- **🕒 Перенести** — бот покажет ближайшие свободные окна, нажмите нужное.
  Клиент получит сообщение о переносе.

Кнопка **«Написать клиенту»** не нужна: просто нажмите на ссылку
`https://vk.com/im?sel=…` — откроется диалог с этим человеком, можно спросить
про самочувствие или договориться о другом времени голосом/текстом.

## Что приходит утром

В 9:00 (время настраивается) приходит список на день:

```
📋 Записи на пт, 23 октября:

✅ 10:30 — Мария Иванова · Массаж спины · +7 (900) 123-45-67
⏳ 15:00 — Ольга Смирнова · Общий массаж · ВКонтакте
```

`✅` — подтверждено, `⏳` — заявка ещё ждёт вашего ответа.
Если записей нет, придёт «свободный день 🌿».

## Напоминания

- Клиенту: за сутки и за 2 часа (можно изменить).
- Вам: за сутки до каждого сеанса — чтобы не забыть подготовиться.

Если клиент отменил запись, напоминания по ней больше не придут.

## Команды, которые можно писать боту текстом

Пишите их прямо в диалоге с сообществом:

| Команда | Что делает |
|---|---|
| `/today` | записи на сегодня |
| `/week` | записи на 7 дней вперёд |
| `/pending` | заявки, которые ждут вашего ответа |
| `/stats` | сколько заявок за 30 дней, сколько подтверждено/отменено |
| `/off 2026-10-25` | сделать день выходным (клиентам он не предложится) |
| `/on 2026-10-25` | снова сделать день рабочим |
| `/block 2026-10-25 14:00-16:00 обучение` | занять часть дня |
| `/unblock` | список занятых интервалов и как их снять |
| `/unblock 3` | снять занятый интервал №3 |
| `/approve 12` | подтвердить заявку №12 кнопкой не вышло — командой |
| `/reject 12 не смогу в это время` | отклонить с вашей причиной (клиент её увидит) |
| `/say Завтра появилось окно в 15:00, пишите` | написать всем, у кого есть запись в ближайший месяц |
| `/days` | показать ваше расписание, как его видит бот |
| `/contacts` | карточка контакта, которую видят клиенты |
| `/help` | этот список |

Дату можно писать и так: `/off 25.10.2026`.

## Выходные, болезнь, обучение

- Уезжаете на день: `/off 2026-11-03`. Бот сразу скажет, если на этот день уже
  есть записи, и перечислит их — этим людям нужно написать и перенести.
- Заняты пару часов: `/block 2026-11-03 14:00-16:00`.
- Заболели надолго: поставьте `/off` на нужные дни, а клиентам с активными
  записями напишите через `/say` (или лично — так теплее).

## Если клиент не пришёл

Заявка остаётся в истории. Отмените её командой `/reject` до сеанса или просто
оставьте — после окончания сеанса она сама станет «завершённой» и попадёт в
статистику `/stats`.

## Что видит клиент

- Меню: **Записаться · Мои записи · Услуги и цены · Связаться · О мастере**.
- В разделе «Связаться» — ваш телефон, WhatsApp, страница ВК, адрес и как вас
  найти. То есть человек всегда может написать или позвонить вам напрямую,
  а не только тыкать кнопки.
- В «Моих записях» он может сам отменить запись — но не позже чем за 3 часа до
  сеанса (срок настраивается). Позже — только через вас.

## Три правила, которые стоит сказать клиентам

1. Запись подтверждает мастер — заявка ещё не гарантия, дождитесь ответа.
2. Отмена/перенос — минимум за 3 часа, иначе мастер теряет время.
3. Если что-то срочное — звоните или пишите в WhatsApp, не ждите бота.

## Что-то не работает?

- Бот не отвечает на сообщения: скорее всего ноутбук уснул или пропал интернет.
  Попросите племянника/сына проверить — [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
- Кнопки «Подтвердить» не нажимаются: напишите `/pending` и подтверждайте
  командой `/approve <номер>`.
- Ничего не сломается, если вы нажмёте не туда: любую заявку можно отклонить,
  перенести, а день — закрыть через `/off`.
