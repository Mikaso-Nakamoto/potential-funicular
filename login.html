Это правда безопасно?

Это учебная страница. В коде нет ни CSS, ни JavaScript, а форма не подключена к серверу: пароль не покидает ваш браузер. В настоящем проекте такие данные передаются только по HTTPS, пароли хранятся в виде хешей, а для входа по почте и паролю обязательны ограничение попыток и двухфакторная защита.

Почему форма отправляет на главную?

Атрибут action="index.html" указан только для того, чтобы кнопка «Войти» ничего не ломала: страница статическая, а без серверной части авторизацию реализовать невозможно. Без JavaScript — тоже.
