# Victoria Falls — макроэкономический терминал

Биржевой сайт с отслеживанием курсов макроэкономики (фиат, крипта, акции MOEX, металлы, индексы рынка) и конвертером по актуальному курсу. Назван в честь водопада Виктория.

Это переработанная версия проекта, перенесённая в этот репозиторий и пересобранная по навыкам из `agent-skills/`: дизайн-ДНК, современная веб-платформа, моушн, доступность, производительность и логика сценариев.

## Быстрый запуск

```bash
cd projects/victoria-falls
python3 -m http.server 8100
# → http://localhost:8100
```

Можно и через `npx serve .` — сборка не нужна, это статический сайт.

## Что изменилось по сравнению с исходной версией

### Дизайн
- **Внешние обои-фотографии больше нет** (`wallpaperscraft.com`, 2048×1152 на чужом домене). Вместо неё — CSS-градиенты «водопадной взвеси» и SVG-зерно: ноль сетевых запросов, нет CLS.
- Новая дизайн-система на **oklch** и CSS-переменных. Гибрид `linear.app` + `stripe` + `mercury` по методике `design-md-library`, акцент — холодный аква 192°.
- Стеклянные сайдбары с многослойными тенями и внутренним светом вместо сплошной серой рамки `3px solid #bebebe` и радиуса 30px «на глаз».
- **Дисплейный серифный логотип** + моноширинные табличные цифры. Курсы больше не «прыгают» при обновлении.
- Все панели получили стаггер-появление, единые состояния `hover`/`active`/`focus-visible`.
- Тёмная тема объявлена явно (`color-scheme: dark`), есть поддержка `prefers-contrast: more`.

### Код разметки
- Убраны **все инлайн-стили** из `index.html` (было ~120 атрибутов `style="..."`).
- Разметка стала семантической: `header` / `main` / `aside` / `section` / `footer`, у каждой панели есть заголовок и `aria-labelledby`.
- Один CSS-файл на 1084 строки заменён на 5 слоёв: токены → база → раскладка → компоненты → блоки.
- Внешний иконочный шрифт `simple-icons-font` (**~1 МБ woff**) заменён на локальный SVG-спрайт из 8 символов. Бренды без свободной лицензии на лого получили аккуратные монограммы `ЦБ`, `MX`, `MS`, `AMZ` и т. д.
- Удалён нерабочий `gratitude.html` (файла не существовало — битая ссылка).
- Стоковая PNG-иконка Vecteezy (чужой лицензионный ассет, имя файла с водяным знаком) заменена на **авторский SVG-favicon**: тёмный квадрат и аква-водопад в цвет акцента.

### JavaScript
- Добавлен `net.js`: `fetch` с таймаутом 7 с, валидацией ответа и **демо-режимом**. Если API недоступен (офлайн, CORS, блокировка) — подставляются синтетические данные в точных форматах настоящих API, а в углу появляется плашка «Демо-данные». Экран никогда не остаётся пустым.
- Удалён мёртвый код: `js/rates.js` и `js/ZbRF.js` (~330 строк, не подключались ни из HTML, ни из модулей; их работу уже выполняет `converter.js`).
- Из шаблонов `render.js` и `converter.js` убраны инлайн-стили — всё переехало в классы (`.asset-row`, `.asset-quote`, `.currency-icon`, `.currency-name`).
- Модальное окно регионов работает через класс `.is-open`, получило фокус-менеджмент, закрытие по `Escape` и по подложке. `alert()` заменён на встроенную подсказку с `role="alert"`.
- Иконки крипты и логотипы ленты получили `loading="lazy"` и `decoding="async"`.
- Ошибки больше не глотаются: вместо `catch (e) {}` — `reportFailure()` с контекстом, а дата обновления получает видимое состояние `loading` / `ready` / `error`.
- Добавлена кнопка **обмена валют** (↓) в конвертере: меняет местами валюты и пересчитывает. Раньше стрелка была декоративной.
- У внешних виджетов TradingView (теплокарта, мини-графики, Pro-график) появился таймаут: если CDN заблокирован, вместо пустого прямоугольника показывается ссылка «Открыть на TradingView».
- Вкладки графика получили `aria-selected` и включение с клавиатуры, у кнопки Pro-режима — `aria-pressed`.
- Исправлен баг графика: цвета точек пушились дважды на каждую свечу, из-за чего подсказки «фактов» вставали не на те месяцы.

### Доступность
- Ссылка «Перейти к содержимому», `role="tablist"` у вкладок графика, `role="status"` + `aria-live` у курса конвертера.
- У полей ввода появились `<label class="visually-hidden">`.
- `:focus-visible` с двойным кольцом на всех интерактивных элементах.
- У декоративных картинок `alt=""` и `aria-hidden="true"`, у содержательных графиков — `role="img"` и `aria-label`.
- Уважение к `prefers-reduced-motion`: останавливаются бегущие строки и все переходы.

### Производительность
- Минус четыре внешних ресурса (фотообои, иконочный шрифт, CSS флагов, CDN-скрипты) — примерно −1.3 МБ и ни одного блокирующего запроса к чужому домену.
- `Chart.js` и `Sortable` лежат в `js/vendor/` с зафиксированными версиями и лицензиями: дашборд открывается и работает офлайн.
- Флаги валют — 45 локальных SVG (46 КБ после gzip), вместо таблицы стилей на 700 КБ.
- `Chart.js` подключается с `defer`; если файл всё же не загрузился, график показывает подсказку, а не падает.
- `preconnect` к доменам API.
- Бегущие строки и панели анимируются только через `transform`/`opacity` — работают на композиторе.
- Медиа-иконки ленивые, разметка не создаёт горизонтального скролла (проверено на 320px).

## Ограничения

- Данные тянутся напрямую из публичных API с клиента. В проде это стоит проксировать через свой бэкенд (в ТЗ упоминались PostgreSQL и Vercel): меньше CORS-проблем, кеширование и единая точка рейт-лимита.
- Виджеты TradingView (теплокарта и мини-графики) остаются внешними: это их код, работающий с их CDN. Отключаются блокировщиком или таймаутом — тогда показывается ссылка на первоисточник.
- Для полной проверки Lighthouse нужен реальный браузер — в этом окружении доступен только статический анализ (разметка, CSS, JS, ссылки).
