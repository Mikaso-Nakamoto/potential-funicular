# UI & Design Systems Skills

Навыки по проектированию интерфейсов, визуальной иерархии, дизайн-системам и структурированию UI-промптов.

## Каталог

- **[`apple-hig-design/`](apple-hig-design/SKILL.md)** — Принципы Apple Human Interface Guidelines: vibrancy/blur материалы, squircle-скругления, типографика SF Pro, тактильный отклик и жесты.
- **[`design-first-ui-prompting/`](design-first-ui-prompting/SKILL.md)** — Построение UI-промптов в виде чётких дизайн-спецификаций: иерархия, сетка, типографика, ограничения и негативные правила.
- **[`frontend-design/`](frontend-design/SKILL.md)** — Создание выразительного авторского фронтенд-дизайна без «шаблонного AI-стиля»: типографические пары, баланс цвета 60-30-10, пространственный ритм.
- **[`google-material-design-3/`](google-material-design-3/SKILL.md)** — Система Google Material Design 3 (Material You): динамический цвет HCT, тональные поверхности, адаптивная сетка, токены и компоненты (Jetpack Compose, Flutter, Web).
- **[`refactoring-ui/`](refactoring-ui/SKILL.md)** — Практические правила дизайна интерфейсов (Steve Schoger & Adam Wathan): иерархия через вес и контраст, многослойные тени, шкалы отступов, grayscale-first подход.
- **[`shadcn-ui-design-system/`](shadcn-ui-design-system/SKILL.md)** — Архитектура масштабируемых веб-интерфейсов на shadcn/ui + Radix UI + Tailwind CSS: CSS-токены, CVA-варианты, доступные компоненты и темизация.
