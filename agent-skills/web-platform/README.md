# Modern Web Platform & Browser Skills (Google Chrome / Edge / Firefox / MDN)

Официальные навыки от команд браузерных движков (**Google Chrome, Microsoft Edge, Mozilla Firefox и MDN**) для написания кода на актуальных возможностях современной веб-платформы вместо устаревших JS-костылей.

## Каталог

- **[`modern-web-guidance`](modern-web-guidance/SKILL.md)** — Покрывает 250 современных возможностей веб-платформы и содержит 200+ офлайн-гайдов в папке `guides/` (`visual-design`, `ui-components`, `ui-behaviors`, `css`, `forms`, `performance`, `accessibility`, `built-in-ai` и др.): нативные диалоги и Popover API, CSS Anchor Positioning, CSS-карусели (`::scroll-marker`), View Transitions, `oklch()`, `subgrid`, Container Queries, `text-box-trim`, анимации входа/выхода `@starting-style` и оптимизация INP.
- **[`chrome-extensions`](chrome-extensions/SKILL.md)** — Разработка расширений для браузера на Manifest V3: архитектура service workers, content scripts, безопасные API расширений и публикация в Chrome Web Store.
