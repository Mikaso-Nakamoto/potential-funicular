# Design Engineering & Micro-Interactions (Emil Kowalski)

Коллекция из **19 навыков** дизайн-инженерии и микро-анимаций уровня Linear, Vercel и Apple, а также шпаргалки [UI Cheatsheet](ui-cheatsheet.md) и [Performance Cheatsheet](performance-cheatsheet.md).

## Каталог

- **[`animate`](animate/SKILL.md)** — Пошаговое создание веб-анимации с нуля: нужно ли анимировать, выбор кривой, длительности и пружинной физики.
- **[`animate-expo`](animate-expo/SKILL.md)** — Построение плавных нативных анимаций в React Native и Expo.
- **[`animation-performance`](animation-performance/SKILL.md)** — Удержание анимаций в бюджете 60/120 FPS: композитные свойства, работа вне главного потока, отказ от layout thrashing.
- **[`animation-vocabulary`](animation-vocabulary/SKILL.md)** — Обратный словарь моушн-эффектов: перевод описания на человеческом языке в точный технический термин и паттерн.
- **[`apple-design`](apple-design/SKILL.md)** — Перенос принципов физического отклика и плавности интерфейсов Apple в веб-разработку.
- **[`ask-sonner`](ask-sonner/SKILL.md)** — Эталонная настройка уведомлений (toasts) на библиотеке Sonner в React.
- **[`break-ui`](break-ui/SKILL.md)** — Стресс-тест вёрстки экстремальными данными: длинные ФИО, неразрывные строки, пустые состояния, 1 символ.
- **[`choreograph`](choreograph/SKILL.md)** — Хореография групповых анимаций: очерёдность, перекрытие таймингов (stagger) и удержание фокуса внимания.
- **[`emil-design-eng`](emil-design-eng/SKILL.md)** — Философия дизайн-инженерии Эмиля Ковальски (Linear / Vercel): полировка UI, микро-детали и принятие решений в моушне.
- **[`find-animation-opportunities`](find-animation-opportunities/SKILL.md)** — Анализ интерфейса на предмет точек, где деликатная микро-анимация улучшит понятность и отклик.
- **[`gestures`](gestures/SKILL.md)** — Свайпы, шторки (drawers/sheets) и перетаскивания с отслеживанием пальца 1:1, инерцией и прерываемостью.
- **[`improve-animations`](improve-animations/SKILL.md)** — Аудит и улучшение существующих анимаций в кодовой базе с готовыми исправлениями.
- **[`learn-taste`](learn-taste/SKILL.md)** — Фиксация дизайнерских правок сессии в переиспользуемые правила вкуса (`DESIGN.md` / проектные гайдлайны).
- **[`mobile-native`](mobile-native/SKILL.md)** — Набор CSS и meta-приёмов, превращающих мобильный веб-сайт в приложение с ощущением нативного iOS/Android.
- **[`pick-ui-library`](pick-ui-library/SKILL.md)** — Выбор проверенных UI-примитивов (drawers, toasts, command menu, диалоги, графики) под задачу.
- **[`prototype`](prototype/SKILL.md)** — Сборка нескольких контрастных вариантов UI-компонента с переключателем для живого сравнения.
- **[`remove-animations`](remove-animations/SKILL.md)** — Поиск и удаление лишних анимаций, которые замедляют частые действия и клавиатурную навигацию.
- **[`review-animations`](review-animations/SKILL.md)** — Строгое ревью моушн-кода по планке качества дизайн-инженерии Linear/Vercel.
- **[`write-swift`](write-swift/SKILL.md)** — Современные паттерны архитектуры и безопасной конкурентности на Swift 6.
