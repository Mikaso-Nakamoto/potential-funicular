# Media — аватары, моушн-ролики, генеративная графика и стоковые изображения

Категория про **производство медиа**: вертикальные рилсы, explainer-видео, аватар который похож на тебя, генеративная графика кодом.

**9 навыков.**

## Каталог

| Навык | Что делает |
| --- | --- |
| [`html-reel`](html-reel/SKILL.md) | Вертикальный 9:16 рилс (Reels, TikTok, Shorts) из поста, лендинга или видео: сценарий по исходнику, голос, HTML-сцены с монтажом по словам |
| [`html-explainer-video`](html-explainer-video/SKILL.md) | Минутный explainer продукта или идеи: сценарий (хук, выгода, туториал, try-it), голос как часы, HTML-сцены |
| [`url-to-motion-design`](url-to-motion-design/SKILL.md) | Моушн-ролик из лендинга, запуска или видео по URL — без голоса, фиксированная длина |
| [`create-ai-avatar`](create-ai-avatar/SKILL.md) | AI-аватар, который выглядит и звучит как ты |

## Связки

- **Запуск продукта:** `html-reel` (рилс) + `html-explainer-video` (минута на лендинге) + `banner-design` из `ui/`
- **Личный бренд:** `create-ai-avatar` → `digital-twin` → `html-reel` с твоим голосом
- **Оформление макета:** `aura-asset-images` или `unsplash-asset-images` + `ui/taste-skill`
- **Генеративная графика для сайта:** `algorithmic-art` даёт `.js`, который встаёт в hero-секцию
