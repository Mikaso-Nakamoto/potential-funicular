# Vercel Agent Skills

Официальная подборка из **9 навыков** от Vercel Labs: аудит веб-интерфейсов, плавные переходы View Transitions, архитектура и производительность React/Next.js.

## Каталог

- **[`composition-patterns`](composition-patterns/SKILL.md)** — Масштабируемые паттерны композиции React-компонентов без разрастания пропсов.
- **[`deploy-to-vercel`](deploy-to-vercel/SKILL.md)** — Автоматизированная подготовка и деплой веб-приложений на Vercel.
- **[`react-best-practices`](react-best-practices/SKILL.md)** — Правила производительности React и Next.js от инженеров Vercel (бандлы, рендеры, загрузка данных).
- **[`react-native-skills`](react-native-skills/SKILL.md)** — Практики создания быстрых мобильных интерфейсов и GPU-анимаций на React Native / Expo.
- **[`react-view-transitions`](react-view-transitions/SKILL.md)** — Плавные переходы между состояниями и страницами на базе React `<ViewTransition>` и View Transitions API.
- **[`vercel-cli-with-tokens`](vercel-cli-with-tokens/SKILL.md)** — Управление проектами и окружениями через Vercel CLI с токен-авторизацией.
- **[`vercel-optimize`](vercel-optimize/SKILL.md)** — Оптимизация скорости, Core Web Vitals и стоимости хостинга проектов на Next.js / SvelteKit / Nuxt.
- **[`web-design-guidelines`](web-design-guidelines/SKILL.md)** — Официальный аудит веб-интерфейсов от Vercel (100+ правил доступности, форм, фокусов, типографики и UX).
- **[`writing-guidelines`](writing-guidelines/SKILL.md)** — Редактура интерфейсных текстов и документации по стандартам ясности Vercel.
